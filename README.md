# drama-admin

当前版本已移除字幕与多语言：消费者界面固定英语，管理端固定中文，内容只维护主文案；原始音频语言仍作为官方发布元数据。

TikTok Minis 官方短剧系统运营后台。

官方与直连运营已分开菜单、发布流程、分类、轮播和热播，需与 feat/veplayer 服务端及权限迁移配套。功能清单见 [完整实现方案](../drama-server/docs/veplayer-implementation-plan.md)，配置与验证见 [实施与上线手册](../drama-server/docs/veplayer-release-runbook.md)。

## 功能导航

菜单由服务端 RBAC 返回，当前新库的分组为：

- 内容管理：剧目、分集、媒资、官方发布进度和 TikTok 标签。
- 官方运营：官方发布、审核记录、上线记录、官方分类、轮播和热播。
- VePlayer 直连运营：发布工作台、上线记录、直连分类、轮播和热播；按应用预览及明确确认后复制官方配置。
- 应用管理：TikTok 应用 ID、名称、Client Key、启用状态和广告位。
- 变现管理：应用级免费集数、激励解锁和 VIP 策略。
- 运营数据：仪表盘指标、投放配置与官方 Minis Link。
- 系统管理：用户、角色、权限和审计日志。

应用编辑不再重复填写 Client Secret 环境变量、BytePlus 账号和空间；媒资拥有方凭据统一在「配置管理」维护。普通应用启用前需要自己的 Client Key，首次保存后不可更换；历史配置在编辑保存时保留。

TikTok 发布流程为“提交审核 → 手动查询审核结果 → 审核通过，待上线 → 确认上线”。发布与分发面板使用手动刷新，关闭或等待页面不会定时查询；查询失败由运营再次点击重试。审核通过不自动上线，确认操作绑定当前版本任务。需与支持人工审核维护接口的服务端配套部署。

剧目页面同时区分编辑草稿与线上版本；发布面板单独展示额外应用授权结果。投放选择器只列出当前应用可使用的线上内容，不读取编辑草稿。

基础信息支持「保存草稿」和「保存并继续」，可先保存无分集剧目。视频页先选文件、核对集序，再点击「开始上传（N 集）」；该数量只包含已选文件或可恢复的任务，缺文件的分集可稍后补充。每集支持独立上传、重试或重新选文件；已上传但确认失败时复用 VID，已成功分集不重传。视频传输期间保持页面打开，已提交服务端处理的任务可在离开后继续；刷新后未传完的本地文件可通过「批量重选文件」一次选回，系统按原文件名和大小匹配分集，未匹配文件不会改动分集。

后台负责业务编排和状态呈现；TikTok Developer Portal、BytePlus VOD Console 与 TikTok Ads Manager 已提供的能力不重复建设。

## 应用逐集奖励配置

变现设置支持免费集数、每次广告解锁集数及每日逐集奖励上限。解锁集数为 1～10000；每日上限为 0～10000，0 表示不限，按当前应用时区的自然日统计。服务端逐用户执行上限并在事务中再次校验，客户端展示不能替代结算。旧客户端不提交新增字段时保留既有值，首次默认解锁一集且每日不限。

2026-09-09 已用真实 Go API 和隔离 MySQL 完成保存、重新读取、后端重启后保留，以及 H5 免费范围／多集解锁／每日上限联动；桌面和 390px 子视口验证输入、保存及无横向溢出。模拟的是平台能力，未执行真实平台发布。

## 部署

测试与生产使用 Docker + 容器内 Nginx：`bash deploy.sh test`、`bash deploy.sh prod`。脚本分别拉取 `test`、`main` 分支，再按环境选择 Dockerfile，构建成功后替换容器，保留最近 5 个镜像。后台容器内监听 80，测试映射到 5174；独立工程 `drama-nginx` 管理公网入口与同源 API 转发，后台部署不操作宿主机 Nginx。首次迁移需先发布网关再发布后台。配置与安装步骤见 [部署说明](docs/deployment-runtime-config.md)。
